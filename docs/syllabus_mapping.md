# CSE3010 Syllabus Mapping

| Course topic / experiment | Project component |
|---|---|
| Image preprocessing & edge detection | `app/preprocessing/image_processing.py` |
| Convolution/filtering | Gaussian blur |
| Histogram processing | Histogram equalization |
| Feature extraction | Harris, HOG, SIFT utilities |
| Image segmentation | Thresholding, morphology, contours |
| Object detection | Classical motion contours + optional YOLO |
| Object tracking | Centroid tracker |
| Background subtraction | MOG2 |
| Optical flow | Farneback dense optical flow |
| Depth estimation | StereoSGBM disparity |
| 3D/depth extension | Calibration/reprojection can be added later |

The project intentionally does not claim every algorithm in the syllabus is implemented. Advanced methods such as full DLT/RANSAC calibration, photometric stereo and complete 3D reconstruction are documented as future extensions.
